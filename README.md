# OpenVINO Skills

A collection of [Agent Skills](https://docs.claude.com/en/docs/claude-code/skills) for working with [OpenVINO](https://github.com/openvinotoolkit/openvino) and the OpenVINO CPU plugin. Each skill lives in its own directory under [`skills/`](skills/) and is defined by a `SKILL.md` file.

## Skills

| Skill | Description |
| --- | --- |
| [`analyze-ov-accuracy-report`](skills/analyze-ov-accuracy-report/SKILL.md) | Analyze the accuracy report generated by OpenVINO to understand the accuracy of the model. Analyze CPU only regression compared to previous metric result. |
| [`audit-ov-cpu-pr`](skills/audit-ov-cpu-pr/SKILL.md) | Audits open pull requests in the OV CPU repository. |
| [`build-openvino`](skills/build-openvino/SKILL.md) | Build OpenVINO and OpenVINO.genai for CPU platform and run llm_bench with LLM models. |
| [`build-openvino-gpu`](skills/build-openvino-gpu/SKILL.md) | Build OpenVINO for Intel CPU and GPU platform. |
| [`build-openvino-windows`](skills/build-openvino-windows/SKILL.md) | Build OpenVINO for Intel CPU and GPU on Windows, then build and verify OpenVINO GenAI on top of that build. |
| [`fix-bug-template`](skills/fix-bug-template/SKILL.md) | Fix a reproducible OpenVINO CPU crash in benchmark_app on latest master (works in older revisions). |
| [`fix-ov-cpu-bug`](skills/fix-ov-cpu-bug/SKILL.md) | Fixes the OV (OpenVINO) CPU bug by debugging the issue on the CPU platform and applying a patch to the affected files. |
| [`generate-presentation`](skills/generate-presentation/SKILL.md) | End-to-end PowerPoint presentation generation from raw materials. Covers summarization, markdown outline, PPTX generation, visual QA, and review-driven revision loops. |
| [`jira-cpu-issue-tracker`](skills/jira-cpu-issue-tracker/SKILL.md) | Generate a daily JIRA issue tracking dashboard for the OpenVINO CPU Plugin component, showing new issues filed, resolved issues, and a running open-issue count trend over a configurable date range. |
| [`ov-industry-intel`](skills/ov-industry-intel/SKILL.md) | Generate a weekly OpenVINO industry intelligence dashboard tracking trending models, inference frameworks, agent ecosystem integration status, OpenVINO gap analysis, and new architecture topology gaps for iGPU/dGPU deployment. |
| [`run-qwen3-next`](skills/run-qwen3-next/SKILL.md) | Run Qwen3-Next OpenVINO IR models with OpenVINO GenAI llm_bench on Windows, including validated setup, CPU fallback, and current GPU limitations. |
| [`skill-writer`](skills/skill-writer/SKILL.md) | Guide users through creating Agent Skills for Claude Code. Use when authoring a new Skill, or when help is needed with SKILL.md files, frontmatter, or skill structure. |
| [`team-dashboard`](skills/team-dashboard/SKILL.md) | Generate weekly team dashboard with GitHub PRs, JIRA tickets (bugs/features), GPU/CPU features, and customer engagement metrics. |
| [`track-ov-contributors`](skills/track-ov-contributors/SKILL.md) | Fetch PR contribution stats (total and merged) for OpenVINO team members from GitHub API and generate HTML dashboard pages with summary cards and monthly stacked bar charts. |

## Usage

Each skill is self-contained in its directory. To use a skill, point your agent (e.g. Claude Code) at the relevant `SKILL.md` file, which contains the instructions and any supporting scripts or templates for that task.
